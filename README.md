An eraser sized music player/walkie-talkie supporting Bluetooth and SD card playback.

## Components
- nRF52840 QFN48 Variant
- MCP73831 Li-ion Charger
- XC6206 3.3v LDO
- MAX98357A I2C AMP
- MP34DT05 MEMS Microphone
- DM3AT MicroSD Slot
- USB-C 6P

## Features
- SD Card & Bluetooth audio playback
- 4 configurable buttons
- Onboard Li-ion battery charger
- Low Power Consumption
- SSD1306 OLED display support
